# mental-map

Interactive, source-grounded learning for a codebase, mechanism, paper, or concept. See the
[full method](SKILL.md).

First use: `$mental-map Help me understand how this project handles a request.`

Resume: `$mental-map Resume from this approved note: [paste the note]. Re-read the sources before
checking its shaky items.`

The resume hook is not saved by default. Write notes only to a specifically approved target and
scope.
